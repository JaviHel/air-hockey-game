# air-hockey-game
An air-hockey game made in vanilla javascript using canvas.

HOW TO PLAY: 
ENTER/PAUSE-GAME/RETURN-MAIN-MENU= [Enter Key]
PLAY NEW MATCH = [Space Key]

PLAYER-ONE(BOTTOM PADDLE): 
STICK = [W,A,S,D]
SHOOT = [J]
MOVE-SLOW = [K]

PLAYER-TWO(TOP PADDLE): 
STICK(ARROW-KEY) = [UP, DOWN, LEFT, RIGHT]
SHOOT = [1]
MOVE-SLOW = [2]
